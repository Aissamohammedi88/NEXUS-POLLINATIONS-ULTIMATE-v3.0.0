## 🚀 Le Concept

La plupart des clients ChatGPT vous obligent à :
1. Créer un compte OpenAI.
2. Générer une clé API.
3. Payer un abonnement (ou des tokens).
4. Installer une application lourde.

**Nexus Pollinations Ultimate brise ces règles.**
C'est un client CLI en Python pur qui se connecte à l'API gratuite de Pollinations. Il n'y a **aucune clé API**. Aucun compte. Aucun paiement. Juste du code qui parle directement aux serveurs.
